SETTINGS API DOCUMENTATION

Scope
- This file documents the recommended settings-service API surface.
- Items 1-38 map directly to the current schema in this repo.
- Items 39-50 are production-grade operational endpoints strongly recommended for a real deployment.
- Items 51-67 are also implemented in this repo through the templates and device/printer schema.
- Items 68-85 still need extra schema and business logic first.

Practical build guidance
- If you only want the current repo's settings domain, build 1-67.
- If you want a stronger POS settings foundation similar to larger platforms, plan for 1-85 in phases.
- If you want a strict MVP first, start with 1-38.

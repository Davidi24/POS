Recommended request shapes

Create table category
- code: string, required, max 50
- name: string, required, max 100
- description: string, optional
- defaultCapacity: integer, required, min 1
- locationType: TableLocationType, optional
- color: string, optional, max 20
- displayOrder: integer, optional, min 0
- active: boolean, optional

Create table
- categoryId: uuid, optional
- tableNumber: string, required, max 30
- name: string, optional, max 100
- capacity: integer, required, min 1
- floor: string, optional, max 50
- positionX: number, optional
- positionY: number, optional
- shape: TableShape, optional
- status: TableStatus, optional
- active: boolean, optional
- qrCodeValue: string, optional, max 255

Create reservation
- customerId: uuid, optional
- reservationCode: string, optional if generated by backend, otherwise max 50
- source: ReservationSource, optional
- partySize: integer, required, min 1
- reservationStart: timestamptz, required
- reservationEnd: timestamptz, required
- contactName: string, recommended if customerId is null
- contactPhone: string, recommended if customerId is null
- contactEmail: string, recommended if customerId is null
- seatingPreference: string, optional, max 50
- specialRequests: string, optional
- internalNotes: string, optional
- depositRequired: boolean, optional
- depositAmount: decimal, required when depositRequired is true
- initialTableIds: array<uuid>, optional
- primaryTableId: uuid, optional
